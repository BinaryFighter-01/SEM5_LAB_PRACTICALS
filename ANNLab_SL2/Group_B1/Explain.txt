### **Code Explanation**

The program implements a neural network with 2 input neurons, a hidden layer of 4 neurons, and 1 output neuron. It uses backpropagation to learn the XOR function, which maps binary inputs (0,0), (0,1), (1,0), (1,1) to binary outputs 0, 1, 1, 0, respectively. Below is a detailed explanation of each part of the code.

#### **1. Imports and Activation Functions**
```python
import numpy as np

# Sigmoid activation function and its derivative
def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def sigmoid_derivative(x):
    return x * (1 - x)
```
- **Import**: `numpy` is used for efficient array operations and mathematical computations.
- **Sigmoid Function**: Maps any real number to the range (0,1), ideal for binary classification. For an input \( x \), it computes \( \sigma(x) = \frac{1}{1 + e^{-x}} \).
- **Sigmoid Derivative**: Used in backpropagation to compute gradients. For a sigmoid output \( s \), the derivative is \( s \cdot (1 - s) \). This measures how sensitive the sigmoid output is to changes in its input.

#### **2. XOR Dataset**
```python
X = np.array([[0,0], [0,1], [1,0], [1,1]])  # Inputs
y = np.array([[0], [1], [1], [0]])          # Expected outputs
```
- **Inputs (`X`)**: A 4x2 array representing the four possible binary input pairs for XOR: (0,0), (0,1), (1,0), (1,1).
- **Outputs (`y`)**: A 4x1 array of the corresponding XOR outputs: 0, 1, 1, 0. XOR outputs 1 when exactly one input is 1, and 0 otherwise.
- The XOR problem is notable because it’s not linearly separable, requiring a neural network with at least one hidden layer to solve it.

#### **3. Network Initialization**
```python
np.random.seed(1)
input_size = 2
hidden_size = 4
output_size = 1
learning_rate = 0.01
epochs = 10000

# Initialize weights and biases
W1 = np.random.randn(input_size, hidden_size)    # Input to hidden weights
b1 = np.zeros((1, hidden_size))                 # Hidden layer bias
W2 = np.random.randn(hidden_size, output_size)  # Hidden to output weights
b2 = np.zeros((1, output_size))                 # Output layer bias
```
- **Random Seed**: `np.random.seed(1)` ensures reproducibility of random numbers for consistent results across runs.
- **Network Architecture**:
  - `input_size = 2`: Two input neurons (one for each bit of the XOR input).
  - `hidden_size = 4`: Four neurons in the hidden layer, allowing the network to learn complex patterns.
  - `output_size = 1`: One output neuron for the binary output (0 or 1).
- **Hyperparameters**:
  - `learning_rate = 0.01`: Controls how much the weights and biases change during each update. A small value ensures stable learning.
  - `epochs = 10000`: The number of times the network processes the entire dataset to learn.
- **Weights and Biases**:
  - `W1`: A 2x4 matrix of weights connecting the input layer to the hidden layer, initialized with random values from a standard normal distribution.
  - `b1`: A 1x4 vector of biases for the hidden layer, initialized to zeros.
  - `W2`: A 4x1 matrix of weights connecting the hidden layer to the output layer, randomly initialized.
  - `b2`: A 1x1 bias for the output layer, initialized to zero.
- Random initialization of weights helps break symmetry, allowing the network to learn diverse features. Biases start at zero as they’ll be adjusted during training.

#### **4. Training Loop**
```python
for epoch in range(epochs):
    # Forward propagation
    hidden_input = np.dot(X, W1) + b1
    hidden_output = sigmoid(hidden_input)
    
    output_input = np.dot(hidden_output, W2) + b2
    predicted_output = sigmoid(output_input)
    
    # Calculate error
    error = y - predicted_output
```
- **Forward Propagation**:
  - **Hidden Layer**:
    - `hidden_input = np.dot(X, W1) + b1`: Computes the weighted sum for the hidden layer. `X` (4x2) dotted with `W1` (2x4) gives a 4x4 matrix, and `b1` (1x4) is broadcasted to each row.
    - `hidden_output = sigmoid(hidden_input)`: Applies the sigmoid function to get hidden layer activations (values between 0 and 1).
  - **Output Layer**:
    - `output_input = np.dot(hidden_output, W2) + b2`: Computes the weighted sum for the output layer. `hidden_output` (4x4) dotted with `W2` (4x1) gives a 4x1 matrix, plus `b2` (1x1).
    - `predicted_output = sigmoid(output_input)`: Applies sigmoid to get the final predictions (values between 0 and 1).
  - **Error Calculation**:
    - `error = y - predicted_output`: Computes the difference between actual outputs (`y`, 4x1) and predicted outputs (4x1). This error drives learning.

```python
    # Backpropagation
    # Output layer gradients
    d_predicted_output = error * sigmoid_derivative(predicted_output)
    
    # Hidden layer gradients
    error_hidden = np.dot(d_predicted_output, W2.T)
    d_hidden_output = error_hidden * sigmoid_derivative(hidden_output)
    
    # Update weights and biases
    W2 += learning_rate * np.dot(hidden_output.T, d_predicted_output)
    b2 += learning_rate * np.sum(d_predicted_output, axis=0, keepdims=True)
    W1 += learning_rate * np.dot(X.T, d_hidden_output)
    b1 += learning_rate * np.sum(d_hidden_output, axis=0, keepdims=True)
```
- **Backpropagation**:
  - **Output Layer Gradients**:
    - `d_predicted_output = error * sigmoid_derivative(predicted_output)`: Computes the gradient for the output layer. The error is scaled by the derivative of the sigmoid function at `predicted_output`, indicating how much the output should change.
  - **Hidden Layer Gradients**:
    - `error_hidden = np.dot(d_predicted_output, W2.T)`: Propagates the error backward to the hidden layer. `d_predicted_output` (4x1) dotted with `W2.T` (1x4) gives a 4x4 matrix.
    - `d_hidden_output = error_hidden * sigmoid_derivative(hidden_output)`: Scales the hidden layer error by the sigmoid derivative at `hidden_output`.
  - **Weight and Bias Updates**:
    - `W2 += learning_rate * np.dot(hidden_output.T, d_predicted_output)`: Updates output layer weights. `hidden_output.T` (4x4) dotted with `d_predicted_output` (4x1) gives a 4x1 matrix, scaled by `learning_rate`.
    - `b2 += learning_rate * np.sum(d_predicted_output, axis=0, keepdims=True)`: Updates output bias by summing gradients across samples.
    - `W1 += learning_rate * np.dot(X.T, d_hidden_output)`: Updates hidden layer weights. `X.T` (2x4) dotted with `d_hidden_output` (4x4) gives a 2x4 matrix.
    - `b1 += learning_rate * np.sum(d_hidden_output, axis=0, keepdims=True)`: Updates hidden biases.
- The updates adjust weights and biases to reduce the error, guided by gradient descent.

```python
    # Print error every 1000 epochs
    if epoch % 1000 == 0:
        loss = np.mean(np.abs(error))
        print(f'Epoch {epoch}, Loss: {loss}')
```
- **Loss Reporting**:
  - Every 1000 epochs, computes the mean absolute error (`np.mean(np.abs(error))`) to track training progress.
  - Lower loss indicates the network’s predictions are getting closer to the actual XOR outputs.

#### **5. Testing the Network**
```python
print("\nTesting XOR function:")
for i in range(len(X)):
    # Forward pass for testing
    hidden_input = np.dot(X[i:i+1], W1) + b1
    hidden_output = sigmoid(hidden_input)
    output_input = np.dot(hidden_output, W2) + b2
    predicted = sigmoid(output_input)
    
    # Convert to binary output (threshold at 0.5)
    binary_output = 1 if predicted[0][0] >= 0.5 else 0
    print(f"Input: {X[i]}, Predicted: {binary_output}, Actual: {y[i][0]}")
```
- **Testing Loop**:
  - Iterates over each input sample (`X[i:i+1]` ensures proper shape for matrix operations).
  - Performs a forward pass:
    - Computes `hidden_input` and `hidden_output` for the hidden layer.
    - Computes `output_input` and `predicted` for the output layer.
  - **Binary Conversion**:
    - `predicted[0][0]` is the sigmoid output (0 to 1). If it’s ≥ 0.5, the binary output is 1; otherwise, it’s 0.
  - Prints the input, predicted binary output, and actual output for comparison.
